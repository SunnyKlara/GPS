---

## A类：需要你去获取的资料和工具

### A1. 杰理AC6323A SDK开发包 ⭐最关键

**是什么：** 杰理科技的芯片开发工具包，里面包含编译器、库文件、示例代码、烧录工具。
**去哪拿：** 联系杰理科技的代理商或FAE（现场应用工程师），签NDA后获取。
**具体需要哪些：**

| 项目 | 说明 | 必须？ |
|------|------|--------|
| SDK源码/库 | AC632x系列的SDK工程，通常叫 `ac632x_sdk` 或类似 | ✅必须 |
| 编译器 | 杰理自己的编译器（通常是 `pi32` 或基于MIPS的工具链） | ✅必须 |
| 烧录工具 | 通常叫 `JL_Download Tool` 或 `JLDownload` | ✅必须 |
| 开发板/最小系统板 | AC6323A的开发板，用于初期调试 | ✅强烈建议 |
| 芯片数据手册(Datasheet) | AC6323A的引脚定义、外设寄存器、电气参数 | ✅必须 |
| BLE HID示例代码 | SDK里的HID相关demo | ✅必须（如果有的话） |
| 原理图参考设计 | 官方参考电路 | 建议有 |

**淘宝搜索关键词：** "AC6323A 开发板" "杰理AC632N 开发板" "JL AC632x SDK"

**注意：** 杰理的SDK不完全公开，需要通过代理商渠道获取。常见代理商：
- 直接找杰理科技官网（www.zh-jieli.com）联系
- 淘宝上有些卖杰理开发板的店铺也提供SDK
- 嵌入式论坛（电子发烧友、21ic等）可能有分享

---

### A2. AT6558A GPS模块资料

**你已经有的：** AT6558芯片的PDF数据手册
**还需要的：**

| 项目 | 说明 | 去哪拿 |
|------|------|--------|
| 模块选型 | 建议用集成了AT6558A的模块，如ATGM336H | 淘宝搜"ATGM336H模块" |
| 模块硬件手册 | 引脚定义、供电要求、天线连接 | 模块卖家提供 |
| NMEA协议文档 | 已经不需要了——我们的解析器已经写好了 | ✅已完成 |
| GPS陶瓷天线 | 12*12mm或更大的有源天线，IPEX接口 | 淘宝搜"GPS有源天线IPEX" |

**推荐模块：ATGM336H-5N** 
- 内置AT6558芯片，已集成LNA和SAW滤波器
- UART输出，默认9600bps
- 供电3.3V，功耗约25mA
- 淘宝价格约10-15元

---

### A3. TM5020A LED驱动资料

**还需要的：**

| 项目 | 说明 |
|------|------|
| TM5020A数据手册 | I2C/通信协议、寄存器定义、段码映射 |
| LED数码管选型 | 6位共阴/共阳数码管（看TM5020A支持哪种） |

**备选方案：** 如果TM5020A资料难找，可以替换为：
- **TM1637** - 最常用的数码管驱动，4位，资料丰富，淘宝大量现成模块
- **MAX7219** - SPI接口，支持8位，资料多
- **HT16K33** - I2C接口，淘宝大量模块

**替换驱动芯片只影响 `drv_led.c` 一个文件，应用层完全不用改。**

### A4. 硬件工具

| 工具 | 用途 | 必须？ | 参考价格 |
|------|------|--------|---------|
| USB转TTL模块 | 调试串口、烧录 | ✅必须 | 5-10元 |
| 万用表 | 测量电压电流 | ✅必须 | 有就行 |
| 逻辑分析仪 | 抓UART/I2C波形 | 强烈建议 | 50-100元（Saleae兼容款） |
| 示波器 | 看信号质量 | 建议有 | 能借就借 |
| 焊接工具 | 焊接元器件 | ✅必须 | - |
| 杰理烧录器 | 烧录固件到芯片 | ✅必须 | 通常开发板带 |

## 总结：你需要做的事情清单（按优先级）

```
1. 🔴 买一块AC6323A开发板（淘宝），让卖家提供SDK
2. 🔴 买一个ATGM336H GPS模块（带天线）
3. 🔴 获取或确认TM5020A数据手册（或决定用替代芯片）
4. 🟡 买USB转TTL模块（如果没有的话）
5. 🟡 买逻辑分析仪（调试用，强烈建议）
6. 🟢 设计原理图（我在03文档里给了参考）
7. 🟢 打样PCB或先用洞洞板飞线验证

拿到1和2后，就可以把代码烧进去开始跑了。
```
