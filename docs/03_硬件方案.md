## 供电方案

```
          ┌──────────┐     ┌──────────┐
 USB 5V──►│  LDO     ├────►│  3.3V    ├──► AC6323A VCC
 或电池   │ AMS1117  │     │  供电总线 ├──► AT6558A VCC
          │ 3.3      │     │          ├──► TM5020A VCC
          └──────────┘     └──────────┘
```

| 模块 | 典型电流 | 峰值电流 |
|------|---------|---------|
| AC6323A (BLE开) | ~15mA | ~30mA |
| AT6558A (定位中) | ~25mA | ~40mA |
| TM5020A + LED | ~20mA | ~50mA (取决于亮度) |
| **总计** | **~60mA** | **~120mA** |

**供电选择：**
- USB供电：5V → LDO → 3.3V，简单可靠
- 锂电池：3.7V → LDO → 3.3V，需加充电管理芯片（如TP4056）
- 车载12V：12V → DCDC降压 → 3.3V

## 按键电路

```
    3.3V
     │
     ├── 10K上拉（如果芯片内部上拉不够强）
     │
 PA0─┤
     │
     ├── [按键开关]
     │
    GND
     │
     ├── 100nF去耦电容（硬件消抖，可选）
```

- 按键未按下：PA0读到高电平（1）
- 按键按下：PA0拉到GND，读到低电平（0）
- 软件中 `hal_gpio_read()` 需要取反：读到0时返回true（按下）

**注意：** AC6323A通常有内部上拉电阻可配置，如果有就不需要外部上拉。

## GPS模块连接

推荐使用 **ATGM336H-5N** 模块（已集成AT6558A + LNA + 滤波器）：

```
ATGM336H模块引脚:
  VCC (3.3V) ──► 3.3V供电
  GND        ──► GND
  TX         ──► AC6323A UART_RX (PA5)
  RX         ──► AC6323A UART_TX (PA6) [可选]
  PPS        ──► AC6323A PA7 [可选]
  ANT        ──► GPS陶瓷天线 (IPEX接口)
```

**注意事项：**
- TX/RX是3.3V TTL电平，直连AC6323A即可
- 模块首次上电冷启动需要30-60秒才能定位
- 天线必须朝天放置，不能被金属遮挡
- TX/RX信号线尽量短，远离2.4G蓝牙天线

## LED数码管连接

TM5020A通过I2C控制数码管：

```
AC6323A                TM5020A              6位数码管
PB0(SCL) ──[4.7K]──► SCL                 
PB1(SDA) ──[4.7K]──► SDA    SEG0-SEG7 ──► 段选a~g+dp
                      VCC    DIG0-DIG5 ──► 位选（6位）
                      GND
```

**替代方案（如果TM5020A资料不全）：**
直接用 TM1637 模块（淘宝2-5元），4引脚数字接口，自带数码管：
```
AC6323A          TM1637模块
PB0 ──────────► CLK
PB1 ──────────► DIO
3.3V ─────────► VCC
GND ──────────► GND
```
TM1637只支持4位，如果要6位需要两个模块或换用MAX7219。

## BLE天线

AC6323A内置2.4GHz蓝牙射频，需要外部天线：

**方案1：PCB板载天线（推荐）**
- 在PCB上画一个倒F天线（Inverted-F Antenna）
- 不需要额外元件，成本最低
- 需要按杰理参考设计来画，匹配网络很关键

**方案2：陶瓷天线**
- 贴片陶瓷天线，如Rainsun AN2051
- 体积小，性能稳定
- 需要匹配电路

**方案3：弹簧天线**
- 最简单，焊一根弹簧天线上去
- 适合原型验证阶段

**开发阶段建议：** 用开发板自带的天线方案，不需要自己设计。

## PCB设计注意事项

1. **GPS天线区域** 周围不要铺铜，保持净空区
2. **BLE天线** 按参考设计走线，天线下方不铺地铜
3. **GPS模块和BLE天线** 尽量拉开距离（>2cm），避免干扰
4. **供电** 走粗线（>0.5mm），每个IC旁边放去耦电容
5. **UART/I2C信号线** 尽量短，远离天线区域
6. **按键** 靠近用户操作的面板边缘

**开发阶段建议：** 不急着画PCB，先用开发板+杜邦线连接各模块验证功能。
