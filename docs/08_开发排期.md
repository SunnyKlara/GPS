### Day 1: SDK安装和环境验证

**目标：** 编译通过 + 烧录成功 + 看到串口输出

- [ ] 安装杰理编译工具链
- [ ] 导入SDK工程到IDE
- [ ] 编译SDK自带的示例工程（如LED闪烁或串口打印）
- [ ] 连接开发板，烧录固件
- [ ] 确认串口能看到printf输出
- [ ] 熟悉SDK的代码结构和API风格

**产出：** 一个能编译、能烧录、能打印的基础工程

---

### Day 2: 创建项目工程 + 系统初始化

**目标：** 把我们的代码框架整合进SDK工程

- [ ] 复制SDK的HID示例工程作为基础
- [ ] 将app/、lib/、config/、platform/目录复制到SDK工程中
- [ ] 创建 hal_ac6323a.c，先实现 hal_system_init() 和 hal_get_tick_ms()
- [ ] 修改Makefile加入新源文件
- [ ] 编译通过（其他HAL函数先写空实现）
- [ ] 烧录运行，确认 app_main_init() 的打印输出正常

**产出：** 框架代码在真机上编译通过并启动

---

### Day 3: UART + GPS对接（上）

**目标：** 芯片能收到GPS模块的NMEA数据

- [ ] 连接ATGM336H模块到开发板（TX→RX, 3.3V, GND）
- [ ] 实现 hal_uart_init() 和 UART接收中断
- [ ] 先写一个简单测试：收到UART数据就打印到调试串口
- [ ] 确认能看到 $GNRMC 语句
- [ ] 将GPS模块放到窗边，等待定位成功

**产出：** 调试串口能看到原始NMEA数据

---

### Day 4: UART + GPS对接（下）+ NMEA解析

**目标：** NMEA解析器在真机上工作正常

- [ ] 把UART接收回调连接到 nmea_parser_feed()
- [ ] 在主循环中打印解析后的速度、时间、位置
- [ ] 到室外测试，验证速度和位置数据的准确性
- [ ] 对比手机GPS，确认速度误差在可接受范围
- [ ] 测试GPS信号丢失和恢复的处理

**产出：** GPS测速核心功能在真机上验证通过

---

### Day 5: I2C + LED显示

**目标：** 数码管能显示数字

- [ ] 连接TM5020A(或替代芯片)到开发板
- [ ] 实现 hal_i2c_init() 和 hal_i2c_write()
- [ ] 发送测试数据，确认数码管亮起
- [ ] 测试显示 "123.4"、时间 "16.30.00"、横杠 "------"
- [ ] 接入 app_display_update()，实现自动显示GPS速度

**产出：** LED数码管显示GPS实时速度

---

### Day 6: GPIO按键 + Flash存储

**目标：** 按键能响应，里程能保存

- [ ] 连接5个按键到GPIO引脚
- [ ] 实现 hal_gpio_init() 和 hal_gpio_read()
- [ ] 测试按键消抖和长按检测
- [ ] 实现 hal_flash_write() 和 hal_flash_read()（用SDK的VM接口）
- [ ] 测试里程保存：移动后断电重启，验证里程保留
- [ ] 测试里程清零功能（长按KEY1）

**产出：** 按键和存储功能正常

---

### Day 7: 功能整合测试（无BLE）

**目标：** 除了BLE之外的所有功能都正常工作

- [ ] 完整运行 app_main_init() + app_main_loop()
- [ ] 测试4种显示模式切换
- [ ] 测试速度显示、里程累计、时间显示、最高速度
- [ ] 到室外实际行走/骑车测试
- [ ] 修复发现的Bug

**产出：** 一个没有BLE但其他功能完整的测速仪

---

### Day 8-9: BLE HID实现

**目标：** 手机能通过BLE连接设备

- [ ] 研究SDK的BLE API和HID示例
- [ ] 配置BLE广播数据（设备名、HID服务UUID）
- [ ] 注册HID Service和Report Descriptor
- [ ] 实现 hal_ble_init()、hal_ble_hid_send_key()
- [ ] 用nRF Connect验证广播数据和GATT服务结构
- [ ] 测试手机连接和配对流程

**产出：** 手机能搜到并连接设备，GATT服务正确

---

### Day 10: BLE HID按键调试

**目标：** 按物理按键能控制手机音乐

- [ ] 连接手机，打开音乐APP
- [ ] 测试播放/暂停功能
- [ ] 测试上一曲/下一曲功能
- [ ] 测试音量+/-功能
- [ ] 在iPhone上测试
- [ ] 在Android上测试
- [ ] 修复兼容性问题

**产出：** BLE音乐控制功能完整可用

---

### Day 11-12: 全功能联调

**目标：** 所有功能同时工作，互不干扰

- [ ] GPS测速 + LED显示 + BLE + 按键同时运行
- [ ] 验证BLE连接不影响GPS解析精度
- [ ] 验证按键操作不影响显示刷新
- [ ] 连续运行2小时无异常
- [ ] 修复联调中发现的问题

**产出：** 全功能可用的原型机
