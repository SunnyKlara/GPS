# 13 - TM1638 段码映射测试

## 测试方法

固件上电后显示 PAGE 0，按 KEY0 切换画面。
你对照下面的图，告诉我实际显示和预期哪里不一样。

按键: KEY0=下一页, KEY1=上一页, KEY2=全亮, KEY3=全灭

---

## 7段数码管段位名称

```
     _a_
    |   |
   f|   |b
    |_g_|
    |   |
   e|   |c
    |_d_|  .dp
```

## 你怎么反馈

看完实际显示，直接告诉我哪里不对，比如：

- "PAGE 0 上排第1位不是1，显示的像个反的7"
- "PAGE 1 全8但每个8的底部横线没亮"
- "冒号全没亮"
- "下排只有3位，第4位完全不亮"
- "数字位置顺序反了"
- "上排和下排的数字混在一起了"

或者你直接用ASCII画出你看到的样子也行，随便画我能看懂。

## 当前映射参数

```c
grid_map[9] = {0, 1, 2, 3, 4, 5, 6, 7, 7}
// D1→GRID1  D2→GRID2  D3→GRID3  D4→GRID4  D5→GRID5
// D6→GRID6  D7→GRID7  D8→GRID8  D9→GRID8(复用)

colon_grid[3] = {1, 3, 6}  // 冒号在GRID2,GRID4,GRID7的高字节
colon_bit[3]  = {0, 0, 0}  // 高字节bit0

dp_grid = 7  // GRID8高字节bit0

seg_table: bit0=a  bit1=b  bit2=c  bit3=d  bit4=e  bit5=f  bit6=g
```
