# 14 - 调试状态跟踪

## 已确认的事实

1. 硬件连接正常：全段点亮测试成功（70颗LED全亮）
2. 编译烧录流程：Code::Blocks Build → download.bat，已跑通
3. TM1638引脚：PA0=DIO, PA1=STB, PA2=CLK（已验证能工作）
4. PA1被TM1638 STB占用 → ADC按键不能配在PA1上
5. 按键硬件：8个按键通过ADC分压接在PA8上（原理图确认）
6. PA5是GPS UART RX → 不能用作调试串口
7. UART0 TX配为NO_CONFIG_PORT → 串口调试不可用
8. 烧录器连着就能供电，不用拔线
9. C99语法（块内变量声明）会导致芯片不启动 → 必须用C89风格
10. 简化后的C89代码 + PA1做ADC按键 → 数码管能亮，自动翻页正常

## 当前固件配置

- UART0 TX: NO_CONFIG_PORT（禁用）
- ADC按键: PA8 + AD_CH_PA8
- KEY_NUM: 3
- 上拉电阻: 22K (R_UP=220)
- TM1638: PA0=DIO, PA1=STB, PA2=CLK

## 当前固件行为

- 上电：显示PAGE 0，每5秒自动翻页（共4页）
- 短按任意键：停止自动翻页，全屏显示该键的KEY编号（0~7）
  - 比如按某个键看到所有数码管都显示"3"，说明那个键是KEY3
- 长按任意键：切换到下一个测试页面
- 4个测试页面：
  - PAGE 0: 数字 1-8 + 冒号 + 小数点
  - PAGE 1: 全8 + 冒号 + 小数点
  - PAGE 2: 只亮冒号和小数点
  - PAGE 3: 全亮(0xFF)

## 按键操作说明

1. 先等自动翻页，确认数码管能亮
2. 逐个短按8个按键，看数码管显示什么数字 → 记录"XX丝印按键 = KEY几"
3. 长按任意键 → 翻到下一个测试页面
4. 对照预期图看显示对不对
