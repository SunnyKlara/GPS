# 17 - 已确认的硬件映射（2026-04-15 测试通过）

## CM4718(TM1638兼容) 关键发现

1. **CM4718 只有 7 个 GRID，RAM 只有 14 字节**（不是 TM1638 的 8 GRID/16 字节）
2. **写 16 字节会导致地址回绕**，GRID8 数据覆盖 GRID1，必须只写 14 字节
3. **SEG = 数码管位，GRID = 段**（和标准 TM1638 用法一致，之前误以为反了）
4. TM1638 协议（0x40/0xC0/0x8F）兼容，通信正常

## SEG → 数码管位置映射（已确认）

```
上排: SEG1(时十) SEG2(时个) [冒号] SEG3(分十) SEG4(分个) [冒号] SEG5(秒个)
下排: SEG6(千)   SEG7(百)   [冒号] SEG8(十)   SEG9(个)   [小数点]
```

| SEG | 字节 | bit | 物理位置 |

| SEG2 | 低字节 | bit1 | 上排第2位(时个) |
| SEG3 | 低字节 | bit2 | 上排第3位(分十) |
| SEG4 | 低字节 | bit3 | 上排第4位(分个) |
| SEG5 | 低字节 | bit4 | 上排第5位(秒个) |
| SEG6 | 低字节 | bit5 | 下排第1位(千) |
| SEG7 | 低字节 | bit6 | 下排第2位(百) |
| SEG8 | 低字节 | bit7 | 下排第3位(十) |
| SEG9 | 高字节 | bit0 | 下排第4位(个) |

## 通信协议要点

- 只写 14 字节（不是 16 字节！）
- 协议: 0x40(自动递增) → 0xC0(起始地址) → 14字节数据 → 0x8F(显示ON最大亮度)
- GPIO: PA0=DIO, PA1=STB, PA2=CLK
- LSB first, CLK 上升沿采样
