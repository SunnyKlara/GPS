# 18 - 项目进度与待办清单

## 项目需求

1. GPS测速，实时显示当前速度
2. 显示累计里程
3. 实时时间显示
4. BLE协议遥控手机播放音乐app
5. 蓝牙连接指示灯（连接常亮，断开闪烁）

### 按键功能（先调5个）
- MODE键：
  - 无音乐有电话：单击接听，再单击挂断，双击回拨
  - 音乐无电话：单击暂停，再单击播放
  - 音乐有电话：单击接听，再单击挂断，双击回拨
- VOL-：音量+
- VOL+：音量-
- PREV：上一首
- NEXT：下一首

## 技术要点备忘

- CM4718只写14字节，不能写16字节（地址回绕覆盖GRID1）
- 杰理编译器只支持C89（不能块内声明变量）
- Code::Blocks编译后尝试运行sdk.elf会报错，忽略即可
- download.bat显示"Device offline"=烧录器没连，必须看到"下载完毕"
- UART0 TX: NO_CONFIG_PORT（PA0给TM1638 DIO）
- ADC按键当前禁用，端口已配PA8/AD_CH_PA8
