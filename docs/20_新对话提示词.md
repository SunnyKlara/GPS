# GPS测速仪项目 - 新对话提示词

## 项目概述
基于杰理AC6323A蓝牙芯片 + AT6558R GPS模块 + CM4718 LED驱动的GPS测速仪。
代码在 fw-AC63_BT_SDK/apps/hid/examples/keyboard/ 目录下。
SDK是杰理AC63系列BT SDK，编译用Code::Blocks，芯片是bd19平台。

## 已完成且之前测试通过的功能
- TM1638数码管显示驱动（PA0=DIO, PA1=STB, PA2=CLK）
- ADC 8按键识别（PA8，已标定）
- 蓝牙HID控制手机音乐（音量加减、上下曲、播放暂停）
- 蓝牙连接指示灯（小数点LED闪烁/常亮）
- 里程VM保存

## 当前被搞坏的问题（需要修复）

### 问题1：按键完全没反应
之前的对话中为了调试GPS，做了以下改动可能导致按键失效：
- 修改了 board_ac6323a_demo.c 中 mask_io_cfg() 的 PA7 设置（从 SOFTFLAG_HIGH_RESISTANCE 改为 SOFTFLAG_OUT1）
- 修改了 board_ac6323a_demo_cfg.h 中 TCFG_UART0_ENABLE（改过DISABLE又改回ENABLE）
- gps_uart.c 中的 gps_uart_init() 有 os_time_dly(100) 阻塞1秒
- 删除了 app_keyboard.c 中的 Telephony Report Map（Report ID 3）
- gps_main.c 中的电话相关函数被反复修改

开机显示 1:10 然后按键无反应，说明系统可能卡在某处或按键事件没传递到 gps_key_event。

### 问题2：VOL+按键功能错误（在按键恢复后需要排查）
物理VOL+按键按下后手机执行的是暂停/播放而不是音量加。
可能原因：ADC按键的key_value映射和KEY_ID定义不匹配。
需要先确认每个物理按键实际产生的key_value是多少。

### 问题3：MODE键电话功能
需求：
- 有电话时：单击=接听，再单击=挂断，双击=回拨
- 无电话时：单击=暂停/播放音乐
注意：BLE HID模式下设备无法获取手机电话状态（HFP未启用），需要用兼容的HID键码方案。
之前用Hook Switch（Telephony Usage Page 0x0B）导致通话中单击变成静音而不是挂断。

## GPS状态（暂时搁置）
AT6558R的32.768K RTC晶振不起振，GPS芯片没有启动，TX线无数据输出。这是硬件问题，两块板子都一样。软件端GPS UART接收代码已就绪（gps_uart.c），等硬件修复后可用。

## 编译烧录流程
1. Code::Blocks打开 fw-AC63_BT_SDK/apps/hid/board/bd19/AC632N_hid.cbp
2. Build → Rebuild（完全重新编译）
3. 输出到 fw-AC63_BT_SDK/cpu/bd19/tools/sdk.elf
4. 运行 fw-AC63_BT_SDK/cpu/bd19/tools/download.bat 烧录

## 重要注意事项
- C89兼容！不能用C99语法（块内变量声明会导致芯片不启动）
- 所有变量必须在函数/块的开头声明
- Report Map修改后必须在手机上删除配对重新配对
- 修改代码后必须在Code::Blocks里Rebuild，不能只运行download.bat
