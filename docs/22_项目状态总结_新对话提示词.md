# GPS测速仪项目 - 新对话提示词（2026-04-27 更新）

## 项目概述
基于杰理AC6323A蓝牙芯片 + AT6558R GPS模块 + CM4718 LED驱动的GPS测速仪。
代码在 `fw-AC63_BT_SDK/apps/hid/examples/keyboard/` 目录下。
SDK是杰理AC63系列BT SDK，编译用Code::Blocks，芯片是bd19平台。
**C89兼容！不能用C99语法（块内变量声明会导致芯片不启动）**

## 产品需求（完整）
1. GPS实时测速，数码管显示当前速度（km/h，精度0.1）
2. 累计里程显示（掉电保存，支持清零）
3. 实时时间显示（GPS UTC→北京时间UTC+8）
4. 蓝牙遥控手机音乐（EDR HID Consumer Control：播放暂停/上下曲/音量加减）
5. 蓝牙HFP电话控制（MODE键：来电接听/通话挂断/无电话暂停音乐，双击回拨）
6. 蓝牙连接指示灯（小数点LED：连接常亮，断开闪烁）

## GPS硬件连接
- AC6323A PB4(TX) → 220R → AT6558R RX（可以发配置命令）
- AC6323A PB5(RX) → 220R → AT6558R TX（接收NMEA数据）
- AC6323A PB6(TX1) → 220R → AT6558R RX1（辅助串口）
- AC6323A PB7(RX1) → 220R → AT6558R TX1（辅助串口）
- AC6323A PA7 → AT6558R ON_OFF（高电平=正常工作）

## 编译烧录流程
1. Code::Blocks打开 `fw-AC63_BT_SDK/apps/hid/board/bd19/AC632N_hid.cbp`
2. Build → Rebuild（完全重新编译）
3. 运行 `fw-AC63_BT_SDK/cpu/bd19/tools/download.bat` 烧录
4. 必须看到 `SPI nor flash online` + `下载完毕` 才算烧录成功
5. `Device offline, only package the file` = 芯片不在线，没有实际烧录

## 重要注意事项
- **C89兼容！** 所有变量必须在函数/块的开头声明
- **绝对不能用os_time_dly()** — 会阻塞app任务导致按键失效
- **不能用SDK UART的TX引脚发GPS配置** — 开启TX=PB4后RX=PB5收不到数据
- **local_irq_disable/enable要谨慎** — 嵌套不匹配会导致系统卡死
- **uart_dev_close后重新open可能失败** — 但set_baud()可以动态切换波特率
- Report Map修改后必须在手机上删除配对重新配对
- 当前蓝牙模式是EDR（不是BLE），因为HFP电话控制需要EDR
- CM4718只有7个GRID/14字节RAM，不能写16字节

## 🔴 紧急问题：蓝牙配对失败 + 按键无反应

### 症状
- 手机搜索到 "AC632N_1" 但配对失败，报"PIN码不正确"或"无法通信"
- 按键按下后数码管没有反应

### 根本原因
app_keyboard.c 被大幅修改，多处偏离了原始SDK的逻辑：
1. `hidkey_vm_deal()` 里的蓝牙模式选择逻辑被改了（原始默认BLE，被改成强制EDR）
2. `HID_TEST_KEEP_SEND_EN` 从1改成了0
3. `hidkey_app_key_deal_test()` 里的按键处理被完全替换（原始用hid_key_click_table查表，被改成gps_key_event转发）
4. `USER_SUPPORT_PROFILE_HFP` 从0改成了1（原始SDK的HID例程不支持HFP）
5. `board_ac6323a_demo_cfg.h` 里 UART0_TX_PORT 从 IO_PORTA_00 改成了 NO_CONFIG_PORT
6. ADC按键端口从 PA1 改成了 PA8，KEY_NUM 从 3 改成了 8

### 解决方案
**必须从原始SDK的app_keyboard.c开始，最小化修改，逐步加入GPS功能。**
不能大幅重写SDK的蓝牙初始化和按键处理逻辑。

原始SDK文件可以通过 `git show upstream/master:apps/hid/examples/keyboard/app_keyboard.c` 获取。

### 正确的集成方式
1. 保留原始SDK的蓝牙初始化、配对、模式选择逻辑不动
2. 保留原始SDK的按键处理框架（hid_key_click_table查表）
3. 只在按键处理里加一个hook调用gps_key_event
4. 只在BT事件处理里加GPS状态通知
5. 只在app_start末尾加gps_module_init和定时器
6. board_cfg.h的改动要最小化（只改必须改的：UART0_TX、ADC端口）
