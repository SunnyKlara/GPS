# GPS测速仪 - 远程烧录测试指南

## 烧录步骤

1. 把收到的整个 `tools` 文件夹放到电脑上（里面包含所有烧录工具和固件）
2. 用杰理SPI烧录器连接板子
3. 双击 `download.bat`
4. 看输出：
   - ✅ 看到 `SPI nor flash online` + `下载完毕` = 烧录成功
   - ❌ 看到 `Device offline, only package the file` = 烧录器没连好，重新检查连接

## 上电后数码管显示说明

### 开机前几秒（诊断模式）

数码管会显示GPS调试信息：

```
上排:  0X : XX : X
       ↑    ↑    ↑
       |    |    NMEA解析成功次数(0~9)
       |    收到'$'字符数(00~99)
       当前波特率编号(0~5)
```

波特率编号对照：
| 编号 | 波特率 |
|------|--------|
| 0 | 9600 |
| 1 | 4800 |
| 2 | 38400 |
| 3 | 115200 |
| 4 | 57600 |
| 5 | 19200 |

```
下排:  XXXX
       ↑
       收到的总字节数(低4位)
```

### 正常工作（GPS解析成功后）

数码管自动切换为正常显示：
- 上排: 北京时间 `HH:MM:S`（冒号闪烁）
- 下排: 当前速度 `XXX.X` km/h

### 按键功能

- **POWER键**: 手动切换到下一个波特率（调试用）
- 其他按键功能不变（音量、上下曲、播放暂停、电话）

## 需要反馈的信息

烧录上电后，请拍照/拍视频发回来，重点关注：

1. **数码管亮不亮？** 如果完全不亮 = 硬件问题（TM1638/供电）
2. **上排显示什么数字？** 特别是：
   - 波特率编号（最左边的数字）在不在变化？（每3秒变一次 = 自动扫描中）
   - '$'字符数（中间两位）有没有增长？（有 = UART在收数据）
   - NMEA成功数（最右边）有没有变成非0？（有 = GPS数据解析成功！）
3. **下排数字在不在变化？** 变化 = UART在收到字节
4. **等1~2分钟后，有没有自动切换成时间显示？** 有 = GPS定位成功，一切正常！

## 常见情况判断

| 现象 | 含义 | 下一步 |
|------|------|--------|
| 数码管不亮 | 硬件问题 | 检查供电、TM1638焊接、PA0/PA1/PA2走线 |
| 下排数字不变(一直是0) | UART没收到数据 | 检查PB5到AT6558R TX的连线、GPS供电 |
| 下排数字在变，但$=0 | 波特率不对 | 等自动扫描，或按POWER手动切换 |
| $>0但NMEA=0 | 收到部分NMEA但解析失败 | 可能有二进制干扰，需要进一步分析 |
| NMEA>0，自动显示时间 | 一切正常！ | GPS测速功能已工作 |
